## Как устроено портфолио

В `projects/` находятся отдельные кейсы. Исходный код хранится в самостоятельных репозиториях со своей историей Git; ссылки на точные рабочие ветки есть в каждом описании.

SkillSwap — командная работа: описаны только мои задачи, а авторство остальных участников сохранено. В индивидуальных проектах отдельно указана помощь ИИ там, где она использовалась. Материалы теории курсов и тексты заданий в этот каталог не включены.
